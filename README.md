# FastFashion — Proyecto final

Mockup de la aplicación **FastFashion**: vestimenta automática impulsada por IA
(Equipo 5 — Desarrollo de aplicaciones móviles).

## Alcance del mockup

- Outfit del día con clima simulado y regeneración (&lt; 5 s)
- Closet con carrusel, filtros por categoría/estilo/color y búsqueda
- Formulario de alta de prenda refactorizado con `Form` / `GlobalKey` / `TextFormField`
- Chat de IA para pedir combinaciones
- Configuración de recordatorios

## Ejecutar

```bash
cd "Proyecto final"
flutter pub get
flutter run
```
